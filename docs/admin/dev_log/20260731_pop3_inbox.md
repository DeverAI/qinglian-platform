# DevLog — 2026-07-31 POP3 收件箱补全轮

## 本轮目标

响应用户反馈：之前 POP3 仅作为可配置参数存在，没有真正的收件箱功能。本轮补全 POP3 收件箱，使管理员能够在后台收取平台统一邮箱的回复邮件、查看内容、标记已读。

## 完成内容

### 1. 设计与文档

- **Design.md**：在"邮件代发系统"模块增加 POP3 收件箱说明；在数据模型辅助表中增加 `email_inbox`。
- **Techniques.md**：新增 POP3 收件箱技术实现条目（标准库 `poplib` + `email.parser.BytesParser`、按 `message_id` 去重、管理员查看/标记已读）。

### 2. 数据库

- `app/database.py` 新增 `email_inbox` 表：
  - `message_id` 用于去重；
  - `subject / sender / recipient / body / raw_size / is_read / received_at`；
  - 索引：`idx_email_inbox_message_id`、`idx_email_inbox_received`。
- 使用 `CREATE TABLE IF NOT EXISTS`，现有数据库在下次启动时自动迁移。

### 3. 后端 API（`app/routers/emails.py`）

新增 POP3 收件箱模块：

- `_decode_str`：解码 MIME 编码邮件头，兼容非标准原始 UTF-8 被解析为 latin-1 的情况。
- `_get_text_body`：优先提取 `text/plain`，否则从 `text/html` 极简剥离标签返回纯文本。
- `_parse_received_date`：解析 `Date` 头，失败时使用当前时间。
- `_load_pop3_settings`：从 `admin_settings` 读取 POP3 配置并校验端口。
- `POST /api/emails/admin/emails/fetch-inbox`：连接 POP3 服务器，拉取全部邮件，按 `message_id` 去重后入库，返回 `fetched/skipped/total`。
- `GET /api/emails/admin/emails/inbox`：分页列表，支持按 `is_read` 筛选。
- `GET /api/emails/admin/emails/inbox/{id}`：查看详情并自动标记已读。
- `POST /api/emails/admin/emails/inbox/{id}/read`：手动标记已读。

健壮性处理：
- POP3 连接使用 `finally` 关闭；
- 单封邮件解析异常捕获并记录 `Err.log`，不影响其他邮件收取；
- 未配置 POP3 返回 `4001`；连接/认证失败返回 `5002`。

### 4. 前端管理后台（`static/admin.html`）

- 顶部 tab 导航新增"收件箱"；
- 新增 `tab-inbox` 面板：一键收取、刷新列表、显示收取统计；
- 邮件列表展示状态/发件人/主题/收件人/时间，未读加粗；
- 点击"查看"打开详情卡片，展示正文并自动标记已读；
- 新增 `loadInbox`、`fetchInbox`、`viewInbox`、`closeInboxDetail` 函数。

### 5. 测试

- `tests/test_api.py` 新增 `TestInbox`：
  - `test_pop3_fetch_and_view`：mock `poplib.POP3_SSL/POP3`，验证收取、去重、列表、查看并标记已读；
  - `test_pop3_unconfigured`：验证未配置 POP3 时返回 `4001`。
- 测试使用 `email.header.Header` 构造符合 MIME 规范的中文主题，确保 `_decode_str` 正确解码。

### 6. 验证结果

- `python -m pytest tests/test_api.py -v`：**20 个测试全部通过**。
- 子 AGENT 故障检测：无阻塞级缺陷。
