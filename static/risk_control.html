风控机制说明

  • 多处备份：审计日志同时写入数据库主表 + 文件日志（storage/risk_audit/YYYYMM.log）+ Err.log（高危操作三处冗余），防删除。
  • 风险分级：info / warn / danger / critical 四级。批量删除、角色变更、封禁、服务开关、阈值修改为 critical，始终触发 2FA。
  • 异常 IP 检测：不在白名单 + 近 7 天未出现过 + 非本地 IP → 判定为异常，任意变更类操作触发 2FA。
  • 2FA 封禁：3 次验证码失败 → 自动封禁该 IP 对后台管理台的访问 + 封禁对应用户账号（永久，需 Root 手动解封）。
  • 令牌复用：已验证的 2FA 令牌绑定操作者，5 分钟内可复用，避免每个高危操作都重验。
