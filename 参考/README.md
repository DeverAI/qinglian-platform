# SVG Picker — 需求驱动的 SVG 图标选择工具

一个基于 PySide6 的桌面工具，帮助你从 SVG 图标库中按需求选择图标，支持需求列表管理、对比替换、筛选导出。

## 快速开始

```bash
python tools/svg_picker.py
```

要求：Python 3.10+，`PySide6` 已安装。

## 功能概览

### 1. 需求列表系统
- **创建/编辑**：点击顶部「加载/创建需求列表」按钮
- **每一项包含**：
  - `内容`（必填） — 如"专注按钮"
  - `说明`（可选） — 如"侧边栏专注模式入口"
  - `可选择数量`（可选，默认1） — 该需求最多可选几个图标
- **模板**：点击「加载模板」可加载内置模板；点击「下载模板」可保存模板文件到任意位置
- **加载外部文件**：点击「从文件加载」加载已有的需求列表 JSON

**需求列表 JSON 格式（模板可下载）：**
```json
[
  {"content": "专注按钮", "description": "侧边栏专注模式入口", "max_count": 1},
  {"content": "AI对话按钮", "description": "AI对话窗口入口", "max_count": 2}
]
```

> 注意：需求列表和自由选择二选一即可导出，不强制互斥。

### 2. 左侧需求面板
三种状态以不同文字颜色区分：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 未选 | 灰色 (#64748b) | 尚未选择任何图标 |
| 已选可增 | 蓝色 (#3b82f6) | 已选但未达上限，可继续添加 |
| 已满 | 红色 (#ef4444) | 已达选择上限 |

- **点击未选/可选项**：提示在右侧点击选择一个 SVG
- **点击已满项**：弹出编辑框，可删除已选图标或修改备注

### 3. 图标选择
- 在右侧 SVG 区域点击任意图标
- 如果该需求尚未有选择 → 直接添加
- 如果该需求已有选择（未满） → 弹出**对比框**

#### 对比框功能
- 左列：展示已有候选图标 + 备注编辑
- 右列：新图标预览 + 名称/分类/颜色
- 操作：
  - **替换选中**：勾选要删除的旧图标（可多选），新图标替换第一个被勾选的（保留其备注）
  - **直接添加**：直接加入为新的选择
  - 右下方显示与新图标相似的已有候选（相似度推荐）

### 4. 筛选
- **颜色筛选**：全部 / light（深色图标） / dark（浅色图标）
- **类别筛选**：根据文件名前缀自动分类（锁、计时、操作、用户…）
- **相似搜索**：输入 SVG 名称，自动匹配相似图标（基于文件名相似度）

### 5. 导出
点击底栏「导出 JSON + SVG」：

1. **JSON 文件**（`svg_export.json`）— 包含：
   - `__comment__` 字段（含使用说明、目录结构、各字段释义）
   - `selections` 列表，每项含：demand, svg_file, svg_path_in_export, category, color_type, note
2. **SVG 文件夹**（`export_svgs/`）— 包含所有选中的 SVG 文件

### 6. SVG 相似识别
基于文件名拆词匹配（`SequenceMatcher`），阈值 0.6。可在对比框和相似搜索中看到推荐。

### 7. 错误处理
- 全局异常自动捕获，写入 `Err.log`
- 所有文件操作异常均记录到 `Err.log`

## 数据文件

所有文件在 `tools/` 目录下：

| 文件 | 用途 |
|------|------|
| `demand_list.json` | 当前需求列表（不含选择结果） |
| `demand_selections.json` | 需求列表 + 选择结果（自动恢复） |
| `demand_template.json` | 内置模板 |
| `svg_mapping.json` | 导出结果（老版本兼容） |
| `.last_svg_path` | 上次浏览的 SVG 目录 |
| `Err.log` | 运行时错误日志 |

## 目录结构

```
tools/
├── svg_picker.py          # 主程序
├── README.md              # 本文件
├── Err.log                # 错误日志
├── svgs/                  # 默认 SVG 图标目录
│   ├── alarm-clock-...svg
│   ├── bell-...svg
│   └── ...
├── demand_template.json   # 需求列表模板
├── demand_list.json       # 保存的需求列表
├── demand_selections.json # 保存的选择结果
└── .last_svg_path         # 上次浏览目录
```
